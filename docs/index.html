telefd2d

telefd2d is a 2D staggered-grid elastic finite-difference (FD/FDM) seismic wave propagation toolkit for rugged topography and near-surface geophysics.

telefd2d 是一个面向地形起伏与近地表地球物理场景的二维交错网格弹性波有限差分工具。

Keywords: telefd2d, seismic, seismology, 2D elastic wave, finite difference, staggered grid, wave propagation, topography, CPML, geophysics.

Core Capabilities

  • 2D staggered-grid velocity-stress elastic FD solver
  • Topography-aware free-surface treatment
  • CPML-style absorbing boundaries with tunable parameters
  • Python baseline + C++ serial/OpenMP backends
  • Decoupled compute and postprocess workflow
